# 4. 主要功能清单

> Index: [docs/PRD.md](../PRD.md)


| 功能 | 说明 | 默认值 / 条件 |
| --- | --- | --- |
| 时间戳转换 | 秒 / 毫秒 / 纳秒与日期互转；顶部实时当前时间（日期 / 时区与时间同一行），纳秒用 `performance.timeOrigin + performance.now()` 高精度计算（约 50ms 刷新，非固定 `000000`）；时间戳单位**自动识别**（≤11 位为秒、≤15 位为毫秒、否则纳秒），无单位选择框；**时间戳 → 日期**与**日期 → 时间戳**的输入框**同一行右侧**各有一个**偏移输入框**（普通文本输入，无下拉预设，见 §10），可输入 `-30m` / `+2h` / `90`（纯数字按秒；单位 `s`/`m`/`h`/`d`/`w`/`mo`，月按 30 天），带符号表示「前（-） / 后（+）」，输出结果叠加该偏移，**默认值为 `+0s`（时间不变）**，清空时同样按无偏移计算；偏移文本非法时输入框描红（`.invalid`）且按无偏移计算；**底部「时间戳差值」**输入两个时间戳 A / B（各自自动识别单位，可混用），实时输出「时间差（秒）」（带符号，最多 9 位小数、去尾零）与「时间差（格式化）」（`天 / 小时 / 分钟 / 秒 / 毫秒` 非零项拼接，负数前置 `-`），按 **B − A** 计算、纯数字运算不经过浮点 | 实时；不可识别的时间戳显示错误；输入与偏移不做历史记录、不落盘 |
| IP / 网段与掩码 | 输入 `IP`、`IP/前缀`、`IP 掩码`、纯数字或 `0x` 十六进制，IPv6 输入 `IPv6` 或 `IPv6/前缀`（前缀 0–128，缺省按 `/128`）；**输入框右侧「本机地址」下拉**（`IPv4 公网地址` / `IPv6 公网地址` / `IPv4 内网地址` / `IPv6 内网地址`），选择后**先清空输入框并显示加载动画（禁用输入）**，获取到地址后自动填入（内网从本机网卡取对应地址族、v4 优先私有网段、v6 优先非链路本地；公网按地址族经外部服务获取出口 IP，遵循系统代理；失败时提示「获取本机地址失败」）；自上而下显示：**归属地** → **IP 进制（十进制 / 十六进制 / 二进制）** → 网段结果（网络地址、广播地址、可用范围、主机数、掩码、反掩码、前缀、掩码二进制、地址类型）。**IPv6**：另显示**展开 / 压缩形式**（展开为完整 8 组冒号分隔、每组补齐 4 位前导 0；压缩按 RFC 5952 最长零段合并）与网段结果（网络地址、最后一个地址、地址范围、地址总数、掩码、反掩码、前缀、掩码二进制（按 16 位分组）、地址类型）；地址类型识别环回 `::1`、未指定 `::`、IPv4 映射 `::ffff:0:0/96`、链路本地 `fe80::/10`、ULA 私有 `fc00::/7`、多播 `ff00::/8` 与公网。**子网划分**：底部「子网数量」输入框，输入 **2 的幂**（如 4 / 8 / 16），实时输出新前缀、子网大小与子网 CIDR 列表（每个子网一行，超过 8 个时仅显示前 8 个并提示），IPv4 与 IPv6 均支持；非 2 的幂、非法数字或超出当前前缀可划分数量（新前缀超过 32 / 128）时提示错误且不显示结果 | IPv4 未给掩码时按 `/24` 计算并提示；**识别出协议后隐藏该协议不可用的分区**：IPv6 隐藏归属地与 IPv4 网段结果（不查归属地），IPv4 隐藏 IPv6 展开 / 压缩与 IPv6 网段结果；归属地卡片固定高度，无运营商显示 `-`；**DNS 查询**：工具末尾独立分区，用系统解析器（Node `dns.promises`）查询 **A / AAAA / MX / TXT / CNAME / NS / SOA** 记录（记录类型下拉 + 域名输入框 + 「查询」按钮，回车亦可），**输入 IP 地址时自动做反向（PTR）查询**；结果逐条列出（`类型 + 序号` + 记录值，各带复制按钮），失败时红字提示具体原因；归属地右侧五个图标按钮（定位 / 全球 / WHOIS / WHOIS / 网络延迟图标）用浏览器打开 `https://ipgeolocation.io/what-is-my-ip/<ip>`、`https://iplocation.io/ip/<ip>`、`https://webwhois.cnnic.cn/WhoisServlet?queryType=Host&domain=<ip>`（CNNIC WHOIS）、`https://wq.apnic.net/apnic-bin/whois.pl?searchtext=<ip>`（APNIC WHOIS）与 `https://ping.pe/<ip>`（ping.pe）（IP 自动替换；无有效 IPv4 时禁用） |
| 单位转换 | 同一工具内包含**进制转换**与**单位转换**两个分区。**进制转换**：二进制 / 八进制 / 十进制 / 十六进制四行单行输入双向实时同步，任一进制输入即换算其余进制；附带位宽（补齐到 8 的倍数）与字节数结果；非法输入标红且不联动。**单位转换**：九个单位单行输入双向实时同步：**字节 (B) / 位 (b) / KiB / MiB / GiB / TiB / Kbps / Mbps / Gbps**；任一单位输入即换算其余（基准为字节；位按 1 位 = 1/8 字节，速率按 1000 进位十进制换算）；非法数字标红且不联动 | 空输入清空其余行；两分区互不影响 |
| JSON 格式化 | 粘贴/失焦后**原地格式化**（固定 4 空格缩进）并语法高亮；工具栏单行：文本/结构切换、键排序、复制、压缩、清空；错误定位（行列）；**结构查看**（可折叠树）；编辑器 / 结构树**占满内容区剩余高度**（工具注册项 `fill: true`，见 §10） | 超过 1MB 仅格式化不高亮；输入改变仅重高亮；不再固定 180px 高度 |
| SSH 管理 | **标题行右侧「快速连接」按钮**（`plus` 图标）：点开固定尺寸弹窗（不可调整大小）——第一行 `root` / `ubuntu` 预设 + 用户名输入（默认选中 `root`）；第二行地址（**必填**）+ 端口（默认 `22`）；第三行密码 + 「确认」。密码留空则用 `~/.ssh/id_ed25519` 密钥连接；弹窗**不因窗口整体失焦自动关闭**（只在点击外部区域 / `Esc` / 提交成功后关闭）；确认后**始终新开一扇终端**执行连接；**无论连接成功与否**都写入 `~/.ssh/config` 的「快速连接」分组（`# group: 快速连接`），该分组恒排在分组列表最前（`ssh:quick-connect`，见 §3.4）。读取 `~/.ssh/config` 列表；每行显示系统图标、`user@host(:port)`（22 不显示端口）、别名、**编辑图标**（隐藏主面板并打开设置 → SSH，直接进入该主机的编辑表单，`ssh:edit`）与**连接按钮**；**双击条目（按钮除外）等同于连接**（连接在悬浮终端窗口里执行，见 §3.8，不会切换桌面）；列表在打开面板时自动刷新（无手动刷新按钮）；系统图标来自缓存的探测结果（品牌彩色图标，探测在「设置 · SSH 管理」进行）；行内 `folder` 图标**打开独立文件窗口并自动连接该主机**（`file-window:open`，见 §3.8-11）；**按分组显示为手风琴**（分组来自 config 的 `# group:` 注释，**默认全部展开**，点分组标题折叠 / 展开；命名分组在前、未分组在后；没有任何命名分组时保持扁平列表） | 忽略通配符主机（如 `Host *`）；未探测显示通用主机图标 |
| 剪贴板 | 主进程按设置周期轮询系统剪贴板，展示最近 N 条记录（默认 **3**，可在设置调整）；文本固定 2 行截断预览，图片渲染为小缩略图，**SVG 代码也渲染为小图（固定 64×64 框内等比缩放）**；每条可复制，支持一键清空历史 | 历史仅存内存、退出即清空；文本超 10 万字截断；图片按「大小+哈希」去重；SVG 超 20 万字符按文本处理 |
| 文本处理 | **字符串输入框更高（5 行）**，其余转换结果保持两行。**编码转换**：字符串 / Base64 / 十六进制 / URL 编码 / **URL 解码** / ASCII 十进制 六个字段双向实时同步（UTF-8）；**URL 编码**保留 URL 结构字符（`encodeURI` 的保留集：`://` `/` `?` `=` `&` `#` `;` `,` `@` `+` `$` 等）**与 `%`**（只编码空格、中文等其余字符），得到各应用可直接识别的可读 URL，且对已编码内容幂等；URL 框回读用**容错反转义**（允许孤立 `%`）；**URL 解码**=`decodeURIComponent` 的**容错反转义**（还原 `%xx` 里的中文等多字节字符、保留 URL 结构；孤立 `%` 等非法转义不报错、尽量还原）；在任意字段输入即可实时得到其余表示。**二维码与 Data Matrix**（各自带分区标题）：两者均为**左=图形、右=参数 + 按钮**，展示区固定 200×200、该行尺寸恒定；Data Matrix 使用 `bwip-js`（形状 / 尺寸 / 版本 / 边框），二维码用 `qrcode-generator`（纠错等级 / 尺寸 / 版本 / 边框，显式 UTF-8），参数下方为「复制」/「下载到本地」；数据源固定为最上面的「字符串」框。**文本处理**（作用于「字符串」框，直接改写其内容；**按钮区紧贴在第一个「字符串」输入框下方**，采用紧凑布局：大小写转换 / 行处理 / 统计的标题与按钮**同一行排列（标题不独占一行）**，统计以行内小标签显示，随该框内容实时更新）：**大小写转换**（全大写 / 全小写 / 驼峰 camelCase / 帕斯卡 PascalCase / 下划线 snake_case / 短横线 kebab-case / 常量 CONSTANT_CASE / 标题 Title Case，**逐行**应用，拆词时先拆驼峰再按非字母数字切分，中文整段视为一个词）、**行处理**（去重（保留首次出现）/ 升序 / 降序（自然排序，数字按数值比较）/ 反转 / 去空行 / 去首尾空格 / 去空白行与首尾空格）、**统计**（行数 / 字符数（按码点）/ 单词数 / UTF-8 字节数 / 去重行数）。 > 原「文本处理」工具已并入本工具（**不再提供 JSON / XML / SQL / URL 转义分区**）。 | 输入非法时标红不联动（URL 解码容错、不标红）；二维码内容为空时按钮禁用、过长时红字提示；纯渲染层实现、不落盘 |
| 哈希计算 | 计算 **MD5 / SHA1 / SHA256 / SHA384 / SHA512 / CRC32 / FNV-1a 32 / FNV-1a 64 / XXH64 / CityHash64** 共 10 种算法（算法清单由主进程 `hash:algorithms` 下发，渲染层据此生成结果行）；支持输入字符串或**选择本地文件**（流式计算，适合大文件）；两段式切换控件保持内容宽度（不占满整行），字符串输入框与文件选择区共用 `--hash-source-height`（76px），切换时下方结果区不跳动；文件选择区为整块虚线框（图标 + 提示 / 文件名同一行居中，选中后行内追加「重新选择」）；切换类型时清空结果 | 字符串输入防抖 200ms；文件经系统对话框选择；CRC32 / FNV / XXH64 / CityHash64 为纯 JS 实现（**已与上游 C++ 参考实现逐字节比对验证**，长度 0–300 随机语料全部一致） |
| 正则测试 | 内容区**不再使用分区标题**（表达式 / 标志 / 常用片段合并为一块，匹配结果紧跟测试文本，替换与模式解释各自紧贴内容）：**表达式 + 标志**（`g i m s u y`，可用按钮切换；非法表达式 / 非法标志就地红字提示且不抛错）、**测试文本**（多行输入框）、**匹配结果**（总数 + 逐条列出：序号、行列位置、匹配文本（超 120 字符截断）、捕获组（编号组 `$1…` 与命名组，各自可复制）；列表最多 200 条并在超出时提示；**零长度匹配会推进游标**，不会死循环；内部始终按全局扫描以列出全部匹配）、**替换预览**（支持 `$1 $2 $<name> $& $` + `` $' `` `$$`，是否全局替换取决于表达式的 `g` 标志）、**常用片段**（邮箱 / URL / IPv4 / 十六进制 / 数字 / 中文 / 日期时间 / 空白字符 / 单词边界，点击填入表达式）、**模式解释**（启发式扫描 `\d \w \s` / 量词 / 锚点 / 分组 / 命名组 / 先行后行断言 / 字符组 / 交替 / 惰性量词等常见构造并给出中文说明，非完整语法解析）；另有「清空」按钮 | 纯渲染层实现；输入变化 180ms 防抖；不落盘 |

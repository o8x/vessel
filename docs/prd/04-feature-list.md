# 4. 主要功能清单

> Index: [docs/PRD.md](../PRD.md)


| 功能 | 说明 | 默认值 / 条件 |
| --- | --- | --- |
| 时间戳转换 | 秒 / 毫秒 / 纳秒与日期互转；顶部实时当前时间（日期 / 时区与时间同一行），纳秒用 `performance.timeOrigin + performance.now()` 高精度计算（约 50ms 刷新，非固定 `000000`）；时间戳单位**自动识别**（≤11 位为秒、≤15 位为毫秒、否则纳秒），无单位选择框；**时间戳 → 日期**与**日期 → 时间戳**的输入框**同一行右侧**各有一个**偏移输入框**（普通文本输入，无下拉预设，见 §10），可输入 `-30m` / `+2h` / `90`（纯数字按秒；单位 `s`/`m`/`h`/`d`/`w`/`mo`，月按 30 天），带符号表示「前（-） / 后（+）」，输出结果叠加该偏移，**默认值为 `+0s`（时间不变）**，清空时同样按无偏移计算；偏移文本非法时输入框描红（`.invalid`）且按无偏移计算；**底部「时间戳差值」**输入两个时间戳 A / B（各自自动识别单位，可混用），实时输出「时间差（秒）」（带符号，最多 9 位小数、去尾零）与「时间差（格式化）」（`天 / 小时 / 分钟 / 秒 / 毫秒` 非零项拼接，负数前置 `-`），按 **B − A** 计算、纯数字运算不经过浮点 | 实时；不可识别的时间戳显示错误；输入与偏移不做历史记录、不落盘 |
| IP / 网段与掩码 | 输入 `IP`、`IP/前缀`、`IP 掩码`、纯数字或 `0x` 十六进制，IPv6 输入 `IPv6` 或 `IPv6/前缀`（前缀 0–128，缺省按 `/128`）；**输入框右侧「本机地址」下拉**（`IPv4 公网地址` / `IPv6 公网地址` / `IPv4 内网地址` / `IPv6 内网地址`），选择后**先清空输入框并显示加载动画（禁用输入）**，获取到地址后自动填入（内网从本机网卡取对应地址族、v4 优先私有网段、v6 优先非链路本地；公网按地址族经外部服务获取出口 IP，遵循系统代理；失败时提示「获取本机地址失败」）；自上而下显示：**归属地** → **IP 进制（十进制 / 十六进制 / 二进制）** → 网段结果（网络地址、广播地址、可用范围、主机数、掩码、反掩码、前缀、掩码二进制、地址类型）。**IPv6**：另显示**展开 / 压缩形式**（展开为完整 8 组冒号分隔、每组补齐 4 位前导 0；压缩按 RFC 5952 最长零段合并）与网段结果（网络地址、最后一个地址、地址范围、地址总数、掩码、反掩码、前缀、掩码二进制（按 16 位分组）、地址类型）；地址类型识别环回 `::1`、未指定 `::`、IPv4 映射 `::ffff:0:0/96`、链路本地 `fe80::/10`、ULA 私有 `fc00::/7`、多播 `ff00::/8` 与公网。**子网划分**：底部「子网数量」输入框，输入 **2 的幂**（如 4 / 8 / 16），实时输出新前缀、子网大小与子网 CIDR 列表（每个子网一行，超过 8 个时仅显示前 8 个并提示），IPv4 与 IPv6 均支持；非 2 的幂、非法数字或超出当前前缀可划分数量（新前缀超过 32 / 128）时提示错误且不显示结果 | IPv4 未给掩码时按 `/24` 计算并提示；**识别出协议后隐藏该协议不可用的分区**：IPv6 隐藏归属地与 IPv4 网段结果（不查归属地），IPv4 隐藏 IPv6 展开 / 压缩与 IPv6 网段结果；归属地卡片固定高度，无运营商显示 `-`；归属地右侧五个图标按钮（定位 / 全球 / WHOIS / WHOIS / 网络延迟图标）用浏览器打开 `https://ipgeolocation.io/what-is-my-ip/<ip>`、`https://iplocation.io/ip/<ip>`、`https://webwhois.cnnic.cn/WhoisServlet?queryType=Host&domain=<ip>`（CNNIC WHOIS）、`https://wq.apnic.net/apnic-bin/whois.pl?searchtext=<ip>`（APNIC WHOIS）与 `https://ping.pe/<ip>`（ping.pe）（IP 自动替换；无有效 IPv4 时禁用） |
| 单位转换 | 同一工具内包含**进制转换**与**单位转换**两个分区。**进制转换**：二进制 / 八进制 / 十进制 / 十六进制四行单行输入双向实时同步，任一进制输入即换算其余进制；附带位宽（补齐到 8 的倍数）与字节数结果；非法输入标红且不联动。**单位转换**：九个单位单行输入双向实时同步：**字节 (B) / 位 (b) / KiB / MiB / GiB / TiB / Kbps / Mbps / Gbps**；任一单位输入即换算其余（基准为字节；位按 1 位 = 1/8 字节，速率按 1000 进位十进制换算）；非法数字标红且不联动 | 空输入清空其余行；两分区互不影响 |
| JSON 格式化 | 粘贴/失焦后**原地格式化**（固定 4 空格缩进）并语法高亮；工具栏单行：文本/结构切换、键排序、复制、压缩、清空；错误定位（行列）；**结构查看**（可折叠树）；编辑器 / 结构树**占满内容区剩余高度**（工具注册项 `fill: true`，见 §10） | 超过 1MB 仅格式化不高亮；输入改变仅重高亮；不再固定 180px 高度 |
| SSH 管理 | **标题行右侧「快速连接」按钮**（`plus` 图标）：点开固定尺寸弹窗（不可调整大小）——第一行 `root` / `ubuntu` 预设 + 用户名输入（默认选中 `root`）；第二行地址（**必填**）+ 端口（默认 `22`）；第三行密码 + 「确认」。密码留空则用 `~/.ssh/id_ed25519` 密钥连接；确认后**始终新开一扇终端**执行连接；**无论连接成功与否**都写入 `~/.ssh/config` 的「快速连接」分组（`# group: 快速连接`），该分组恒排在分组列表最前（`ssh:quick-connect`，见 §3.4）。读取 `~/.ssh/config` 列表；每行显示系统图标、`user@host(:port)`（22 不显示端口）、别名、**编辑图标**（隐藏主面板并打开设置 → SSH，直接进入该主机的编辑表单，`ssh:edit`）与**连接按钮**；**双击条目（按钮除外）等同于连接**（连接在悬浮终端窗口里执行，见 §3.8，不会切换桌面）；列表在打开面板时自动刷新（无手动刷新按钮）；系统图标来自缓存的探测结果（品牌彩色图标，探测在「设置 · SSH 管理」进行）；行内 `folder` 图标**打开独立文件窗口并自动连接该主机**（`file-window:open`，见 §3.8-11）；**按分组显示为手风琴**（分组来自 config 的 `# group:` 注释，**默认全部展开**，点分组标题折叠 / 展开；命名分组在前、未分组在后；没有任何命名分组时保持扁平列表） | 忽略通配符主机（如 `Host *`）；未探测显示通用主机图标 |
| 剪贴板 | 主进程按设置周期轮询系统剪贴板，展示最近 N 条记录（默认 **3**，可在设置调整）；文本固定 2 行截断预览，图片渲染为小缩略图，**SVG 代码也渲染为小图（固定 64×64 框内等比缩放）**；每条可复制，支持一键清空历史 | 历史仅存内存、退出即清空；文本超 10 万字截断；图片按「大小+哈希」去重；SVG 超 20 万字符按文本处理 |
| 编码转换 | 字符串 / Base64 / 十六进制 / URL 编码 / **URL 解码** / ASCII 十进制 六个字段双向实时同步（UTF-8）；**URL 编码**保留 URL 结构字符（`encodeURI` 的保留集：`://` `/` `?` `=` `&` `#` `;` `,` `@` `+` `$` 等）**与 `%`**（只编码空格、中文等其余字符），得到各应用可直接识别的可读 URL，且对已编码内容幂等；URL 框回读用**容错反转义**（允许孤立 `%`）；**URL 解码**=`decodeURIComponent` 的**容错反转义**（还原 `%xx` 里的中文等多字节字符、保留 URL 结构；孤立 `%` 等非法转义不报错、尽量还原），在任意字段输入即可实时得到其余表示。**最下方为二维码区与 Data Matrix 区（各自带分区标题）**：两者均为**左=图形，右=参数 + 按钮**；**展示区固定 200×200、该行尺寸恒定**（改变任何参数都不影响展示大小）。Data Matrix 使用 `bwip-js`，参数为**形状**（方形 / 矩形）、**尺寸**（导出 PNG 256 / 512 / 1024 / 2048px）、**版本**（自动 / 对应形状的 RxC 尺寸）、**边框**（静区 0–8，默认 1），数据源与二维码相同（最上面的「字符串」框）；复制 / 下载逻辑与二维码一致（下载文件名 `datamatrix.png`）。二维码数据源固定为最上面的「字符串」框内容、实时生成（`qrcode-generator`，矢量 SVG；**显式把库的 `stringToBytes` 设为 UTF-8**，避免中文乱码）；右侧参数：**纠错等级**（L / M / Q / H，默认 M）、**尺寸**（= 导出 PNG 边长 256 / 512 / 1024 / 2048px，默认 1024，不影响展示大小）、**版本**（自动 / 1–40，默认自动；版本过小放不下内容时红字提示）、**边框**（静区模块数 0–8，默认 1），除尺寸外改动即时重绘；参数下方为**左对齐**「**复制**」/「**下载到本地**」按钮：复制=把二维码渲染成 1024×1024 PNG 写入剪贴板（`app:copy-image`），下载=保存对话框存为 PNG（`app:save-image`） | 输入非法时标红不联动（URL 解码容错、不标红）；二维码内容为空时按钮禁用、过长时红字提示；不落盘 |
| 哈希计算 | 计算 **MD5 / SHA1 / SHA256**；支持输入字符串或**选择本地文件**（流式计算，适合大文件）；两段式切换控件保持内容宽度（不占满整行），字符串输入框与文件选择区共用 `--hash-source-height`（76px），切换时下方结果区不跳动；文件选择区为整块虚线框（图标 + 提示 / 文件名同一行居中，选中后行内追加「重新选择」）；切换类型时清空结果 | 字符串输入防抖 200ms；文件经系统对话框选择 |
| 2FA 验证码 | 顶部单行输入框（右对齐「添加」按钮）：接受 **`otpauth://totp/…` 链接**或**裸 Base32 密钥**（忽略空格 / 连字符 / 小写）；点「添加」由主进程校验非法 / 重复后解析并添加 —— 链接自动解析出**标题（issuer）**与**副标题（账号 label）**（UTF-8 解码，支持中文；无 issuer 时用 label 作标题），裸密钥标题为「未命名」。下方以**卡片**实时展示：**绿色盾牌图标** + 标题 + 副标题（同一行、超出省略）、**逐位验证码数字块**（6 或 8 位、按 3/3 或 4/4 分组）、**倒计时秒数**与**进度条**（≤5 秒变红，按各自 `period`）。卡片右侧依次为**复制**按钮（`copy`，一键复制当前验证码并就地显示 ✓ 反馈）与**删除**按钮（`trash`）→ 就地二次确认（`确认删除？` + ✓ / ✕）后删除。验证码由主进程按账号的 `period` / `digits` / `algorithm`（SHA1 / SHA256 / SHA512）计算、渲染层每 250ms 刷新倒计时、时间片切换时拉取新验证码 | 输入非法 / 重复时就地红字提示并闪烁输入框；列表持久保存（密钥加密，见 §5.1）、重启保留；输入不做历史记录 |
| 游戏 | 主界面新增「游戏」TAB（位于 TAB 最右）：按 FC / GBC / GBA / N64 / SFC 分类展示 ROM（固定 8 列），支持 `roms/<engine>/<文件夹>/xxx.rom`（单 ROM 子目录以文件夹名展示；多 ROM 子目录生成 `<引擎> - <文件夹>` 独立分类，扩展名大小写不敏感），封面优先取 ROM 同目录同名 `.png/.jpg/.jpeg/.webp`，否则用主题中性色占位封面（无彩色渐变，忽略括号内容、显示前两个有效单词，连接字符不计入长度，最多 16 个字符或 8 个汉字，不显示引擎类型）；顶部不显示工具栏与工作目录路径，**工具标题行右侧**提供 350px 宽的**模糊搜索框**（单击游戏时用完整名称更新 placeholder）；分类为可折叠**手风琴**，卡片**分批渲染**（`IntersectionObserver`，每批 120 个）以支撑几千个 ROM；进入工具页自动刷新，已启动过的游戏按最近启动倒序置顶于「最近启动」分类（最多 8 个）；单击选中、双击（或选中后 Enter）在独立游戏窗口启动 EmulatorJS。工作目录默认未打包为 `assets/games`、打包为 `应用数据目录/games`，结构为 `roms/{fc,gbc,gba,n64,sfc}` + `profiles/<gameId>/`；电池存档每 15 秒 / 暂停 / 关闭时写入 `profiles/<gameId>/battery.srm`，手动即时存档写 `state.slot1`（+ `state.slot1.png`）；游戏窗口失焦自动暂停、重新聚焦自动继续（仅自动暂停时） | EmulatorJS 4.2.3 离线内置；单游戏窗口复用；窗口默认 / 最小 480×320、最大 1440×900、支持全屏、不始终置顶；控制区悬浮在画面上（显示 / 隐藏不改变画面尺寸），含确认 / 选择 / 暂停 / 重启 / 保存 / 读取 / 截图 / 快进 / 静音 / 音量 / 适配画面 / 全屏，可隐藏并恢复；全屏自动隐藏标题栏与控制区 |
| 设置 · 游戏 | 工作目录（选择 / 重置默认 / 打开目录）；**FDS BIOS**（选择 `disksys.rom` 后自动复制到 `games/bios/`，可清除，默认未配置）；五个平台的**通用按键**（方向 WASD、A=Space、B=鼠标左键、X=鼠标右键、Y=J、L/R=Q/E；N64 通用方向映射到摇杆）+ N64 专有按键（十字键方向键、Z=鼠标右键、C=IJKL，标注「N64 模拟器专用」）；功能快捷键（Start=Enter、Select=Shift、暂停 Esc、保存 F5、读取 F9、快进 F、全屏 F11、静音 M、显隐控制区 Tab）；通用按键提供「恢复 PC 风格（鼠标）」/「恢复传统风格（不使用鼠标）」两个预设按钮（同时重置 N64 专有键，传统风格 N64 Z=KeyR），未配置时默认 PC 风格；冲突 / 非法按键拒绝保存 | `settings.gameWorkDir` / `gameFdsBios` / `gameCommonKeys` / `gameKeymaps` / `gameHotkeys` / `gameVolume` / `gameControlsHidden` |
| 营养成分 | 输入商品名（无独立标题标签）与每 100g 的能量(kJ)/蛋白质/脂肪/碳水/钠及商品总重，实时换算盐、千卡、千焦（含每日推荐对比）与慢跑 / 步行消耗；名称输入框右侧为**保存按钮 + 记录下拉**：按商品名保存输入，**忽略大小写去重 / 同名覆盖**；切换记录回填输入时按钮变为「删除」，删除需二次确认（4 秒未确认自动复位，再次编辑输入则回到「保存」）；下方 **TDEE 计算器**（性别 / 年龄 / 身高 / 体重 / 活动水平，**无默认值、需手动填写**；Mifflin-St Jeor 计算 BMR 与 TDEE，**结果同时显示 kcal / kJ**）自动记录输入与计算结果；营养成分的**每日推荐优先使用当前 TDEE**（kcal 与 kJ），未填写 TDEE 时回退 2250kcal / 9410kJ，并新增「**TDEE ÷ 每 100g**」商（约等于多少份 100g）；底部保留**复制**按钮，已移除清空按钮 | 商品记录与 TDEE 最后状态持久化到 `nutrient-records.json`；TDEE 输入变化防抖自动保存；商品需点「保存」才写入 |
| 设置 · 应用 | 语言（自绘下拉）、外观（跟随系统/浅色/深色）、主题色、开机自启（调试模式 / 未打包运行时不注册）、**Liquid Glass**（主界面启用系统玻璃背景：macOS 26+ 用原生 Liquid Glass，旧系统回退 hud 毛玻璃，见 §8.1）、**Liquid Glass 透明度**（滑块 0–100，越大越透明，**实时生效**；默认 80；仅开启 Liquid Glass 时显示）、剪贴板条数、剪贴板轮询间隔、**遵循系统代理**（开关，默认关；开启后终端命令 / SSH / SFTP / 更新按 macOS 系统代理 / PAC，SSH / SFTP 仅 SOCKS5，见 §3.9）。关于（版本号 + **检查更新**按钮（`app:check-updates`，见 §7；**每次打开主界面或设置界面时自动静默检查一次**，自动检查期间按钮禁用并显示「检查更新中…」）+ **开发者模式开关** `settings.developerMode`，默认关，值持久化）、开发者（**仅开发者模式开启时显示**；打开主界面 / 设置界面 / **终端界面** / 文件界面 DevTools，`devtools:open` 的 `main` / `settings` / `terminal` / `file`） | 见 §5.1 |
